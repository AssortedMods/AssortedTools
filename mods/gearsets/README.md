# Assorted Gear Sets

Adds pickaxes, shovels, axes, hoes, swords, spears and armor in tin, copper, silver, aluminum, nickel, platinum, lead, bronze, electrum, invar, steel, ruby, amethyst, sapphire, topaz, emerald and peridot. You need another mod that adds the ingot or gem to craft them.

Also included in [Assorted Tools](../tools). Worlds made with Assorted Tools 11.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
